## 无损压缩发布包

本次发布版本为 v1.1.0-preview.2-lossless，沿用上述功能与素材内容。无损优化改变 PNG 编码字节，保持尺寸、透明度及解码后的 RGBA 像素一致；不应再用压缩前 PNG 的文件哈希检验本版。

- 2,148 个 PNG 完成无损优化与像素一致性检查；1 个扩展名为 PNG 的 JPEG 保留原字节。
- 4 个 ZIP 合计 3,629,800,543 字节，6,467 个压缩包文件通过 CRC 与逐文件 SHA-256 校验。
- 2026-10-24 发布前重新核对 4 个 ZIP 的 SHA-256，与 `SHA256SUMS.txt` 一致。GitHub 和百度网盘使用同一组安装包。
- 上述本地安装记录属于压缩前的 preview.2；未将 lossless 包重新安装到游戏中作为额外验证。
