# 使用大猪扎

选择游戏目录后，配置器会打开本机网页。页面中的勾选是草稿，需要点击“保存并应用配置”；重新启动游戏后生效。

- 点击素材预览可对照原图和猪化图。英雄可切换查看头像与立绘。
- “筛选结果：全部猪化 / 全部原版”作用于所有符合当前条件的结果，包括其他分页。
- 模块开关保留单项偏好；重新打开模块会恢复之前的选择。
- 暂未完成的英雄皮肤和停用概念卡不能启用。
- 导出包含当前草稿；导入先进入草稿，检查后保存。
- 快捷键：`/` 搜索，`Ctrl+S` 保存，`Ctrl+Z` 撤销选择。
- 多窗口修改时会检查版本冲突，先重新载入再保存。

## 配置、升级和备份

配置：游戏目录下 `BepInEx/config/PigModSuite/settings.json`。

保存备份：同目录的 `backups/`。可通过配置器导入备份 JSON。

安装备份：`BepInEx/PigModSuite-backups/日期时间/`。里面有本次修改清单与原文件；更新安装保留统一配置。

先退出游戏和配置器再升级。同名插件会原位更新，不会另装一套重复插件。安装器不会修改其他 Mod 或 BepInEx 核心。

## 停用与卸载

临时停用可在配置器点击“全部使用原版”，保存后重启游戏。

完全卸载时先退出游戏与配置器，将下列 5 个文件夹移出 `BepInEx/plugins/`：
`PigCardArt`、`PigEncounterArt`、`PigPortraitArt`、`PigStorageArt`、`PigMainMenuArt`。
再移出游戏根目录的 `PigModConfigurator/` 和 `Open-PigModConfigurator.cmd`。
可以保留 `BepInEx/config/PigModSuite/` 方便日后恢复偏好。游戏原始资源文件没有被改写。

## 问题排查

- 缺少素材：检查 Core 与所有 Assets ZIP 是否来自同一版本，并解压合并。
- 不能安装：确认选择的是包含 `TheBazaar.exe` 的目录，且游戏、配置器已退出。
- 网页关闭后安装仍提示配置器运行：在系统托盘退出配置器。
- 某套皮肤仍显示原版：确认它已完成且已勾选，并重启游戏。
- 客户端更新后贴图不匹配：先关闭对应模块，记录游戏版本与具体资源 ID。
